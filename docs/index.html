    HOW TO USE IT

    Up and running on localhost in 2 minutes.

    Requires only Node.js 20+. Ollama is optional and can even be installed and managed directly from the in-app Settings modal on macOS & Linux.

    STEP 01

    Clone & Install

    Grab the repository and install dependencies locally.

    git clone https://github.com/nikosrz/NeuroForge.git
cd NeuroForge
npm install
    STEP 02

    Launch Locally

    Start the dev server (or build for daily production use).

    npm run dev
# Or production mode:
npm run build && npm start
    STEP 03

    Connect & Fight

    Open http://localhost:3210, then open Settings to plug in your JIRA credentials, private .ics calendars, and local Ollama. 

    http://localhost:3210
    Tip: Want to test the Command Room before connecting corporate JIRA? Launch it right away — Clean Base-Camp mode lets you try Mind-Dump (M), stage controls, and local Ollama before entering any API token.
